Kebijakan Privasi

Berlaku sejak 24 November 2026

Kebijakan ini menjelaskan data apa yang diakses oleh MyBach Studio, yaitu aplikasi internal milik MyBach (dikelola oleh Mulya Bachtera), serta bagaimana data itu dipakai, disimpan, dan dihapus.

1. Siapa pengguna aplikasi ini

MyBach Studio adalah alat pribadi untuk satu pengguna, yaitu pengelola MyBach. Aplikasi ini tidak terbuka untuk umum, tidak menyediakan pendaftaran, dan hanya terhubung ke akun media sosial milik MyBach sendiri.

2. Data yang diakses

Dengan izin pengelola melalui login resmi masing-masing platform (OAuth), MyBach Studio mengakses:

  • YouTube (YouTube API Services): mengunggah video, mengisi judul, deskripsi, dan jadwal tayang, serta membaca informasi channel MyBach dan statistik agregat videonya (jumlah tayang, suka, komentar).
  • Facebook & Instagram (Meta Graph API): menerbitkan dan menjadwalkan Reels di Halaman Facebook dan akun Instagram milik MyBach, serta membaca statistik agregatnya.
  • TikTok (Content Posting API): mengunggah video ke akun TikTok milik MyBach dan membaca informasi dasar akun tersebut.

MyBach Studio tidak mengumpulkan data pribadi penonton, tidak membaca pesan pribadi, dan tidak mengakses akun orang lain.

3. Penggunaan data

Data hanya dipakai untuk menerbitkan video MyBach dan memantau kinerjanya. Data tidak dijual, tidak disewakan, tidak dipakai untuk iklan, dan tidak dibagikan kepada pihak ketiga.

Penggunaan dan pemindahan informasi yang diterima dari Google API oleh MyBach Studio mematuhi Kebijakan Data Pengguna Layanan Google API, termasuk ketentuan Penggunaan Terbatas (Limited Use).

4. Penyimpanan & keamanan

Token akses disimpan terenkripsi di komputer pribadi pengelola, di dalam aplikasi otomasi n8n yang tidak dapat diakses publik. Token tidak pernah ditulis ke berkas biasa, repositori kode, atau layanan pihak ketiga. Video dan metadata disimpan di komputer yang sama.

5. Layanan pihak ketiga

MyBach Studio menggunakan YouTube API Services. Dengan menonton atau berinteraksi dengan konten MyBach di YouTube, Anda tunduk pada Persyaratan Layanan YouTube dan Kebijakan Privasi Google. Konten di Facebook, Instagram, dan TikTok juga tunduk pada kebijakan privasi masing-masing platform.

6. Mencabut akses & menghapus data

  • Akses Google/YouTube dapat dicabut kapan saja melalui halaman izin akun Google.
  • Akses Facebook/Instagram dapat dicabut melalui Pengaturan → Aplikasi dan Situs Web di akun Facebook.
  • Akses TikTok dapat dicabut melalui Pengaturan → Keamanan → Aplikasi dengan izin di aplikasi TikTok.

Setelah akses dicabut, token yang tersimpan tidak lagi berlaku dan dihapus dari aplikasi. Statistik agregat yang tersimpan dihapus dalam 30 hari setelah permintaan penghapusan diterima melalui kontak di bawah.

7. Anak-anak

Konten MyBach tidak ditujukan untuk anak di bawah 13 tahun, dan MyBach Studio tidak mengumpulkan data dari anak-anak.

8. Perubahan kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Tanggal berlaku di bagian atas halaman akan disesuaikan setiap kali ada perubahan.

9. Kontak

Pertanyaan atau permintaan penghapusan data dapat dikirim melalui pesan langsung (DM) Instagram @mulyabachtera.
